# Applied-Gregtech---Minecraft-Modpack
*(日本語の概要は下にあります)*

## Overview
This modpack serves as an introductory experience for **GregTech**.
It is a pack where you can enjoy precise line construction and technological evolution, combining **GregTech CEu Modern** with powerful automation tools like **Applied Energistics 2**.

### 🏭 Custom Content (Blocks, Items, and Machines)
Beyond standard mods, this pack features its own **custom blocks, items, single-block/multi-block machines, and generators**.

### ⚒️ Abundant Resources
From early-game world generation to the endgame, you will never run out of **ores or fluid resources**. With **Ex Deorum's** sifting mechanics and large-scale machinery, ores effectively become an **infinite resource**.

### ⚡ Seamless Fusion of GregTech and AE2
Designed to provide an environment where setting up your **AE2** network is smooth and intuitive. **AE2** itself becomes accessible in the **late LV age**, and **autocrafting** unlocks starting from the **MV age**.

## Featured Mods
* **GregTech CEu Modern**
* **Applied Energistics 2**
* **Ex Deorum**
* **Torcherino** - Accessible only in the very late endgame.

## Installation
1. Download the latest `Applied-Gregtech-x.x.x.zip` from GitHub `Releases` or the repository.
2. Launch your modded Minecraft launcher (Note: The official Vanilla `Minecraft Launcher` cannot be used directly).
3. Select "Create New Profile" or "Import" and choose the downloaded zip file.
4. Once the instance is created, launch the game.

## Recommended Settings
### Allocated Memory (RAM)
* **Minimum:** 4GB
* **Recommended:** 8GB+

### Keybindings
Since **FTB Ultimine** is included, it is highly recommended to configure its keybindings upon your first launch.

## 概要
このmodpackは、**Gregtech**の入門となる**modpack**です。  
**Gregtech ceu Modern**と**Applied Energistics 2**などの強力な自動化を組み合わせた、緻密なライン構築と文明の進化を楽しむパックです。
### **🏭独自のブロック・アイテム・機械**
  既存のmodだけでなく、**パック独自**の**ブロック**や**アイテム**、**単一機械**や**マルチブロック機械**、**発電機**などがあります。
### **⚒️豊富な鉱石資源**
  ワールド生成時からエンドゲームまで、尽きることのない**鉱石**や**液体資源**があります。  
  **Ex Deorum**のふるいや大型機械で鉱石は**無限資源**と化します。
### **⚡GregtechとAE2の融合**
  **AE2**のネットワークを簡単に組み立てられるような環境を目指しています。  
  **LV時代後期**から**AE2**自体は使え、**MV時代**から**自動クラフト**が使えるようになります。
