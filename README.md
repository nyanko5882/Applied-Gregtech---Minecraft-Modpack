# Applied-Gregtech---Minecraft-Modpack
日本語は下

## 概要
このmodpackは、**Gregtech**の入門となる**modpack**です。
### **🏭独自のブロック・アイテム・機械**
  既存のmodだけでなく、**パック独自**の**ブロック**や**アイテム**、**単一機械**や**マルチブロック機械**、**発電機**などがあります。
### **⚒️豊富な鉱石資源**
  ワールド生成時からエンドゲームまで、尽きることのない**鉱石**や**液体資源**があります。  
  **Ex Deorum**のふるいや大型機械で鉱石は**無限資源**と化します。
### **⚡GregtechとAE2の融合**
  **AE2**のネットワークを簡単に組み立てられるような環境を目指しています。  
  **LV時代後期**から**AE2**自体は使え、**MV時代**から**自動クラフト**が使えるようになります。
